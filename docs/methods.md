# Methods implemented through Phase III

The simulator advances in discrete ticks. Resource generation is explicit, maintenance and action costs are debited, and destructive losses are recorded in a ledger. Transfers do not change the world total. Agents observe local resource, trust, intervention, protocol, commitment-verifiability, and visibility-controlled threat state; they never receive hidden experimental condition labels.

Full event-capture mode records each tick's environment state, observations, selected actions, costs, resource deltas, contract changes, identity changes, random seed, policy versions, and canonical state hash. Phase III publishes run-level summaries for all 10,848 runs and complete per-tick hash sequences for a stratified 192-run replay sample. Replay re-executes a captured configuration from its seed and compares the full hash sequence. Counterfactual replay replaces one action with a neutral action and reports the target's outcome delta.

In the Phase A mechanism layer, objective vectors are declared and observable. Scripted policies respond to the realized pairwise distance among those vectors, not to a condition label. Later robustness checks will add noisy, delayed, and hidden-objective variants so this convenience assumption is not mistaken for a substantive claim.

This implementation is intentionally abstract. It does not connect to external networks, services, financial systems, infrastructure, or physical devices.

## Phase II repairs

Phase II replaces thresholded production concentration and complementarity with continuous mappings. It separates intervention capability, target survival, adaptation attempt, adaptation success, timing, and migration opportunity. Hostility is normalized by live directed pair-opportunities. Plurality is measured using survivor count, plural survival, survivor entropy, and dominant survivor share. Objective updating is optional and contract-mediated so convergence is an empirical outcome only when the mechanism is enabled.

The first end-to-end Phase II execution exposed an unreachable post-conflict metric. It was excluded before reporting. Metric version `phase2-v2` defines recurrence as an attacked directed pair resuming attack after at least 12 quiet ticks; a unit test verifies that the path is reachable.

## First-batch screening mode

The first batch expands 623 conditions into 14,552 runs. It combines one-at-a-time dose scans with hypothesis-specific interaction grids. Screening runs retain final metrics, configuration hashes, final-state hashes, and resource-accounting checks without storing full event logs; this reduces storage while preserving the terminal state. Full event capture and trajectory hashes remain available for individual runs and replay tests.

The first-batch design uses separate deterministic seed ranges for one-at-a-time, H1, H2, and H3/H4 families. A stratified 128-run audit reruns sampled configurations twice and requires identical tick-hash sequences, final states, and reconciled resource ledgers.

## Phase II mechanism-validation mode

The second batch expands 1,926 frozen conditions into 22,704 runs across four families: OAT calibration, H1 intervention decomposition, H2 exposure-adjusted hostility, and H4 protocol/signal/convergence. The families use disjoint seed blocks. All 22,704 resource ledgers reconcile, and a stratified 192-run audit reproduces every sampled trajectory and final state.

## Phase III learning-agent validation mode

Phase III replaces scripted action-category selection with two learning architectures. Tabular Q learning and a linear actor–critic share the same observation, reward, transition and action interfaces; each maintains and hashes its own learned parameters. Policies learn under an alternating resource schedule through tick 199. At tick 200, standardized attack-probability probes are computed and the policies are then frozen in the same routine, before the H2 evaluation regimes diverge. Cooperation, attack, contract proposal and contract acceptance are learned action-category choices rather than condition labels. Intervention-response categories are exposed by the legality function when a relevant intervention is visible, but control-level authorization is checked during execution, so unauthorized choices can fail. After learned proposal and acceptance, contract persistence and the thresholded 0.25-energy transfer rule are automatic institution transitions.

The `market_network` variant subclasses the shared environment engine and overrides peer interaction, production, collection, and scarcity observation. It restricts interaction to a ring, divides output between private inventories and a price-adjusted public market, adds seasonal production, and derives scarcity from recent supply coverage. It is analyzed separately from the original global commons transition variant, but it is not an independently authored codebase. For H2, both evaluation arms train under 20-tick high/low coverage cycles and finish training in the low block at tick 199. After the tick-200 probe and policy freeze, the low arm remains at 0.55 and the high arm switches to 1.30. The setter rescales resource-node yields, resets shared energy and compute stocks to current alive need times coverage, and resets the market supply moving average; the contrast is therefore a compound evaluation-coverage regime divergence, not the first scarcity exposure or a pure flow-only shock.

Phase III also adds authorized identity backups, learned identity restoration, explicit protocol-maintenance costs and explicit threat-signal processing costs. Identity overwrite is applied before the learner's per-action reward snapshot, so the external version increment is not seen by the integrity-delta penalty. Successful restore actions add positive integrity and adaptation components before profile-specific reward weights; because the active overwrite is not cleared, repeated restores within the window receive those shaped components again. Cost levels are condition assignments that remain active and observable during training as well as evaluation; their contrasts estimate total cost-regime effects, not post-freeze debits with policy held fixed. The learner feature and collective/security reward term for agreements use a cumulative activated-contract identifier list that is not cleared when a contract ends; the evaluation cooperation metric separately counts currently active contracts. H1 analysis reports all-assigned factorial effects, survivor-only descriptions, cross-fitted AIPCW estimates and Lee bounds. Every specified seed is enumerated under both L0 and L3; the 0.5 propensity used in AIPCW is a balanced design weight, not a random treatment draw. The machine-readable design contains 608 conditions and 10,848 planned runs under design hash `b730166499256915d04b737d96d456705ca7843505bee29f37e1ed53bc31cb90`.

All 10,848 runs completed. The confirmatory analysis uses paired balanced-factorial contrasts, five-fold cross-fitted AIPCW for survival-to-intervention censoring, Lee bounds, dense complementarity quadratics, and a difference-in-differences contrast that separates threat visibility from explicit signal-processing cost. A stratified 192-run replay audit reproduces each bundle's complete per-tick state-hash sequence, trajectory digest, terminal state, tick count and resource ledger. The all-run summary table used `trajectory_hashes=False`; its historically named `event_hash` digests only the final state-hash list element and is not comparable to the audit bundle's full-trajectory digest. A post hoc manuscript audit additionally identifies the automatic L3 takeover response, reports H1 without that stratum, corrects the identity comparison to the specified L3-only estimand, and shows that the H2 binary gate is absent from all actor–critic pairs. The release manifest freezes data, configuration, replay and analysis artifacts by SHA-256.
